# my-pets

可爱小狗 IP 内容项目 —— 以「问天」为主角的剧情型视频与周边视觉资产工厂。

## 三个角色

- **问天** — 主角小狗
- **炼狱** — 竞争对手（与问天对抗）
- **白城** — 大佬 / 权威（层级在两者之上）

## 快速开始

每次在本项目工作，**先读 `AGENTS.md`，再读 `HANDOFF.md`**。

- 想直接开工 → 说 `puppy-studio` 或 `/小狗视频`，触发一键工作流（会自动读规矩、确认、生成、验收、写回交接）
- 想了解规则 → 读 `AGENTS.md`
- 想知道项目进展 → 读 `HANDOFF.md`
- 想了解角色设定 → 读 `PROJECT.md`
- 想了解怎么生成 → 读 `PRODUCTION.md`

## 文件地图

| 文件 | 作用 |
|---|---|
| `AGENTS.md` | 总纲与行为准则（最高优先级，先读） |
| `HANDOFF.md` | 交接：现状、已定决策、待办、踩坑 |
| `PRD.md` | 产品需求：定位、受众、内容规划、IP 路线 |
| `PRODUCTION.md` | 制作规范：16:9、一致性、生成流程、验收 |
| `PROJECT.md` | 主角档案：问天/炼狱/白城 + IP 资产 |
| `PREFERENCES.md` | 用户偏好与禁忌 |
| `.workbuddy/skills/puppy-studio/SKILL.md` | 一句指令触发的完整工作流 |

## 换电脑继续

```bash
git clone https://github.com/hanbing428/my-pets.git
cd my-pets
# 然后先读 AGENTS.md 和 HANDOFF.md，或从这句开始：puppy-studio
```
